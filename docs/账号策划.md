# 抖音账号策划 · 中英文双语名称与简介

## 定位回顾

- 内容形态：硬科学 × 心理学科普短视频（147 秒/期，代码逐帧渲染动画）
- 统一理论：意识是一个系统，有秩序也有混乱（心理熵为母概念）
- 已规划选题：心理熵（Ep.01 已发布）→ 心流（Ep.02）→ 多巴胺 / 依恋 / 拖延（备选）

## 名称方案

### 方案 A（主推）：心理熵实验室 | PsyEntropy Lab

- **中文**：心理熵实验室（简称"心理熵"）
- **英文**：PsyEntropy Lab（Psychic Entropy 缩合，独一无二、可全平台注册）
- **理由**：
  1. 第一期视频已让"心理熵"三个字建立认知，账号名承接搜索流量；
  2. "实验室"后缀自带系列感与专业感，天然适合多期连载；
  3. 统一理论清晰——全频道都在回答同一句话：**你的大脑为什么越来越乱**；
  4. 每期选题都是心理熵的一个侧面：心流=负熵、拖延=启动熵、焦虑=思维熵、多巴胺=熵的化学开关，内容永远不会跑题。

### 方案 B：脑内宇宙 | Neuroverse

- 覆盖面最广，任何脑科学话题都装得下；英文 Neuroverse（Neuro+Universe）好读好记。
- 适合未来想扩展到非心理学脑科学（记忆、睡眠、专注）的路线。

### 方案 C：杂念粉碎机 | Mind Declutter

- 直击内耗/焦虑人群痛点，转化导向最强；
- 略口语化，会稀释"硬科学"定位的差异化。

### 方案 D：熵减研究所 | Entropy Down Lab

- 呼应金句"你要么熵增，要么进化"，粉丝可自称"熵减人"；
- "熵"字对路过的普通观众有理解门槛。
