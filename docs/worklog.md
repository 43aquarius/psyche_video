# 工作日志 · 心理熵 Ep.01（快节奏版重建）

## 背景说明

本仓库为**完全重建版本**。原制作环境（含旧版 18 场景慢节奏成片）因沙箱重置丢失，
依据既有技术方案重新制作，并按用户反馈全面提速：

> 「视频动画稍微快一些些，目前的内容太少了，动画太慢了，一个小片段好几秒」

## 重建要点

1. **素材找回**：通过 agent-browser 打开抖音分享页（aweme 7693502270637444362），
   从网络请求中提取 DASH 分离流（video-avc1 + audio-mp4a），curl 携带 Referer 下载，
   ffmpeg 校验：视频 1024x576/30fps/147.0s，音频 44.1kHz 立体声/147.17s。
2. **节奏改版**：18 场景 → **38 场景**（翻倍），平均停留 8.2s → **3.9s**；
   入场动画统一压缩到 0.2-0.3s；每场景至少两层信息（主标题 + 数据/图形/标签）；
   长间隙段（45.9-85.1s、100.8-147s）细分为多场景。
3. **动画引擎**：`window.seek(t)` 纯函数式驱动（无 CSS animation），38 场景注册制，
   glitch 标题、胶囊进度条、手机 UI、粒子布朗运动（mulberry32 确定性随机）全部数据驱动。
4. **字体修复**：沙箱内 Noto Sans SC 变量字体注册名损坏（家族名含字面方括号），
   从 googlefonts/noto-cjk 下载 SubsetOTF SC 四个静态字重安装到 ~/.local/share/fonts。
5. **渲染**：Playwright 4 页并行 + JPEG q92 + 智能帧率（入场 1.3s 与粒子场景 30fps，
   静态尾段 15fps），3244 采集帧展开为 4410 输出帧，总耗时 123s。
6. **合成坑**：前台 ffmpeg 长任务会与工具管道假死（孤儿进程连锁 + 前台阻塞），
   解法：同一 bash 调用内后台启动 + progress 文件轮询；编码 42s 完成（3.5x 速度）。
7. **质检**：渲染前 31 张预览图三批 VLM 质检通过；成片 11 个时间点抽帧两批 VLM 质检通过；
   竖屏/横屏封面 VLM 质检通过（无遮挡、无乱码、CTR 评价正面）。
